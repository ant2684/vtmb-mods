# Protean & Frenzy Improved 1.4

## What's new in 1.4

- **Protean 5 restores your previous weapon** when you return to human form, provided you can still use it.
- **The transformation uses third person.** Your previous view returns once you're fully human again. If you change the view during the transformation, the game keeps your choice.
- **Claws sneak attacks have new effects.** Blood follows the wound, with new sounds when Protean Claws or Tiger's Claws strike and pull free.

## Installation

Requires Vampire: The Masquerade - Bloodlines, Unofficial Patch 12.0 and Game Mod Loader. Close the game, back up the files you will replace, and extract the game ZIP into the folder containing `Vampire.exe`. Start the game with Unofficial Patch active. To keep your settings when updating, copy your custom values into the new INI.

The `README.txt` in the game ZIP lists the full set of features and provides uninstall instructions.
