# Native boundaries

The runtime exposes only loaded_vampire and loaded_client. Startup INI parsing
enables eight scoped implementations; Inventory readiness controls only its
dependent transform and custom melee features. Matching model-pool isolation
has its own signature/ownership guards and does not depend on those options.

The collector calls the native implementation once, retains original order and
weights (including zero). Only the confirmed local player outside owned Frenzy
receives custom combos. Other actors receive stock-prefixed records; player
Frenzy retains the counter/controller/serial/class checks. Other models without
the prefix forward unchanged. Models preserve authored ordinary combos and append the stock pool.

Native event/task ownership replaces the old mod Python support. Effects and
inventory remain bound to validated actors/serials; stale queued exits cannot
outlive their owning scene. Legitimate direct commands remain available outside
owned scenes. The game still runs its own original scripts.

Hook groups verify supported bytes before transaction, restore original page
protection and instruction visibility, and retain reachable helper storage if
rollback cannot safely detach it. Production has no diagnostic plugin or logging.
Game/resource inputs remain external to this source tree.
